API ที่หน้าบ้านนี้ใช้ (v1)

Base URL: /api/v1 · รูปแบบ JSON · เวลาเป็น ISO 8601 (+07:00) · ปีพุทธศักราชแปลงที่ฝั่ง frontend · หน้า Board ด้านซ้ายเรียกผ่าน api.* (ตอนนี้เป็น mock)

GET/site-info

หัวข้อ, ชื่อหน่วยงาน, ช่องทางติดต่อ (header + footer)

GET/stations

รายการสถานีสำหรับ dropdown · query: complex_code (optional, เช่น MTP)

GET/aqi/criteria

เกณฑ์ระดับ AQI + ช่วงความเข้มข้นต่อพารามิเตอร์ (ตารางด้านขวา + legend) — cache ได้นาน

GET/stations/{station_id}/readings/latest

ParamInTypeReqคำอธิบาย
station_idpathstring✓รหัสสถานี เช่น MTP-NFP
datetimequeryISO 8601ไม่ส่ง = ค่าล่าสุด; ส่ง = ค่าของชั่วโมงนั้น (ปัดลงเป็นต้นชั่วโมง)
parametersquerycsvกรองพารามิเตอร์ เช่น PM10,NO2,SO2 (default ทั้งหมดที่สถานีวัด)

ตัวอย่าง request ปัจจุบัน:

GET /api/v1/stations/{{ query.station_id }}/readings/latest?datetime={{ encodeURIComponent(isoFromLocal(query.datetime)) }}
